### 支援 ```IOS``` 加密

# [ZIP Vault](https://duckodes.github.io/EncryptZIPmobile)

## 架構
- 格式：ZIP
- 壓縮：DEFLATE
- 加密：AES-256
- 輸出：`.zip`
- 架構：純前端
- 伺服器：無

## 相容性
| 平台 | 支援 |
|--------|--------|
| 7-Zip | ✅ |
| WinRAR | ✅ |
| Bandizip | ✅ |
| Windows 內建 | ⚠️ |
| macOS | ✅ |
| iZip (iOS) | ✅ |
| Documents (iOS) | ✅ |
| Android 解壓軟體 | ✅ |
| 檔案 (IOS) | ⚠️ iOS 版本 |

## 平台支援性

### 支援
- 多檔案選擇
- 建立 AES ZIP
- 下載 ZIP
- iZip 解壓
- Documents 解壓

### 不支援
- 從瀏覽器直接選資料夾
- `webkitdirectory`

## 安全性
- 檔案不會上傳
- 密碼不會上傳
- 所有處理皆於瀏覽器本機完成
